# Brand & Identity: ResonaDSP (Clean-Room Rebrand)

Rebranding and market positioning for the Equalizer APO modern replica.

---

## 1. Selected Brand Identity: **ResonaDSP**
- **Rationale:** Combines *Resonance* (acoustic tuning and precision balance) with *DSP* (Digital Signal Processing). Distinct, short, and conveys studio-grade engineering.
- **Alternative Candidates Evaluated:**
  1. *SonarForge* — Sound craft / gaming audio angle.
  2. *AuraPeak* — Audiophile harmonic curve focus.
  3. *Equalis Pro* — Direct functional clarity.
  4. *AetherEQ* — Zero-latency lightweight system driver.

## 2. Voice & Tone
- **Voice Pillars:**
  - *Surgical & Precise:* We speak like audio engineers, not marketing hype. Use exact measurements (dB, Hz, Q, latency in ms).
  - *Bulletproof & Reliable:* Focus on system stability: zero audio dropouts, persistent hooks that survive Windows updates.
  - *Transparent & Open:* Clean-room architecture, open presets (AutoEq/REW import), privacy-first local processing with no telemetry.
- **Tagline:** *"Studio-grade system audio processing for Windows that stays alive."*

## 3. Visual Identity & Palette
- **Primary Studio Theme (WCAG AAA Certified):**
  - Background (`--color-bg`): `#0d1117` (Deep Slate Obsidian)
  - Surface (`--color-surface`): `#161b22` (Graphite Layer)
  - Accent / Signal (`--color-accent`): `#58a6ff` (Precision Cyan/Blue)
  - Danger / Peak Clip (`--color-danger`): `#ff7b72` (Digital Clipping Red)
  - Success / Active APO (`--color-success`): `#3fb950` (Verified Hook Green)
- **Typography:** Inter (UI elements) + JetBrains Mono (Numeric dB/Hz readouts and DSP AST).

## 4. Trademark & Legal Clean-Room Guardrails
- **Sweep Restrictions:**
  - Codebase, identifiers, and UI strings strictly avoid trademarked names of original software in user-facing elements.
  - Configuration format remains compatible through standard declarative syntax (`Preamp:`, `Filter:`, `GraphicEQ:`).
