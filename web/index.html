Мастер быстрой настройки микрофона

Добро пожаловать в Equalizer FD CRAFT! Давайте настроим ваш рабочий микрофон в 2 простых шага.

Выберите микрофон, с которого идет ваш голос (любой USB-микрофон, Realtek, гарнитура).
Рекомендуется выбрать CABLE Input (VB-Audio Virtual Cable). Звук с микрофона будет моментально обрабатываться эквалайзером и передаваться в Discord/OBS без перезагрузки ПК и без изменения системного реестра.
Подсказка: вы сможете сменить микрофон или вывод в любой момент в панели инструментов.

Профессиональный редактор конфигураций и высокопроизводительный движок цифровой обработки звука (DSP) для Windows.

  • Прямой WASAPI Real-Time аудиомост (микрофон - VB-Audio Virtual Cable)
  • Встроенный Roland BOSS RC-505 Mk2 DSP процессор (Granular Beat Scatter, Space Reverb, Slicer, Vinyl, Vocoder, Isolator)
  • Поддержка 98 VST плагинов из комплекта APO-PLUGINS и сторонних 64-битных VST DLL
  • Параметрические фильтры Biquad IIR и 15-полосный графический эквалайзер ISO
  • Система автообновлений через GitHub Releases с атомарной заменой исполняемого файла
  • Многовкладочный интерфейс пресетов, адаптивный оконный режим, работа без консоли

Установка и настройка VB-Audio Virtual Cable
Зачем нужен виртуальный кабель?
Equalizer FD CRAFT обрабатывает ваш микрофон в реальном времени и отправляет звук в виртуальный кабель (CABLE Input). В Discord, Telegram, OBS, CS2 и Skype вы выбираете устройство ввода CABLE Output — и собеседники слышат обработанный звук студийного качества.
Текущий статус в системе: Проверка...
Порядок установки:
  1. Нажмите синюю кнопку выше и подтвердите права Администратора (UAC).
  2. В открывшемся окне официального установщика нажмите Install Driver.
  3. Перезагрузите ПК или перезапустите аудиослужбу в настройках программы.
  4. В Discord / Telegram / OBS в устройствах ввода выберите CABLE Output (VB-Audio Virtual Cable).
